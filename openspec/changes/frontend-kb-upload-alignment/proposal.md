# F4 知识库与上传闭环

## 背景与目标

F3 已于 2026-10-01 验收归档，当前正式前端已完成首批框架与聊天正文/来源。下一切片将 `/kb`、`/kb/:id` 的资料管理体验对齐冻结 Demo，让用户能够创建/编辑知识库、上传文件、识别处理结果，再进入该知识库的新问答。唯一正式落点仍为 `rag-frontend/`。

本 change 为 Type C：多页视觉迁移、新增本地网格/文档筛选与指定知识库问答导航，并修复既有接线中的前端状态问题。2026-10-02 用户已确认方案执行并授权本轮 Agent 提交，进入实施；真实调用及接受/归档未授权。

## 范围

- 列表：Demo 页头、工具栏、列表与网格切换；名称/描述筛选明确只针对已加载知识库；创建、编辑、统计、删除及空/错/加载/筛选无结果状态。
- 详情：返回与操作区、名称/描述、三项真实统计、文档主区和基本信息侧区；窄屏按阅读顺序堆叠；向量身份仍可展开查看。
- 表单：重复打开编辑正确回填，失败保留输入、展示规范化错误；提交期间防重复；公开/私有文案遵守 tenant 内公开及既有授权语义。
- 上传：沿用最多 5 文件逐个上传；202 与 taskId 表示已接受；成功项移出待选列表，失败项保留，后续提交只发送仍待选文件。响应丢失不能保证未被接受，不自动重发。
- 任务/刷新：复用唯一 poller；状态读取失败仅恢复查询同一 taskId；终态及删除成功后刷新文档、统计与相关列表事实，处理局部刷新失败与旧路由响应。
- 问答入口：详情页“开始提问”进入 `/chat?kbId=<id>`，加载可访问列表后校验并选库，不自动发送 ask；非法/不可访问 ID 明确提示并禁止误选其他 KB。

## 权限与副作用

2026-10-02 用户批准本方案实施并授权本轮 Agent 提交，不借用 F3 授权。baseline 接受、归档、push/PR/发布/部署另按有效授权处理。

规划与后续封闭 fixture 验证不连接真实后端，不产生 provider 调用或真实业务写入。真实 KB 创建可能修改向量存储；上传会触发解析/embedding/vector 写入，问答可能触发 embedding/rerank/generation 与 query/history 写入。执行前另呈交专用 KB、文件、问题、实际模型/provider、最大调用数、服务端重试/timeout、数据出站、费用依据及本地副作用预算；当前这些参数未批准，真实调用预算为 0。cleanup/真实删除不自动包含。

## 完成标准

工程、合成测试、含 vue-tsc 的正式 build、深浅/三视口视觉、键盘/焦点/恢复和范围安全检查分开报告。完整 F4 闭环另需专用授权数据的真实证据；未执行真实链路时只能报告工程/合成/视觉完成，保留未完成任务。若用户仅接受展示与客户端状态契约，须明确调整验收范围后才能接受 baseline/归档，不能用 fixture 代替真实 provider 结果。
