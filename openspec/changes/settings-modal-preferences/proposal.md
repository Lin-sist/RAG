# 设置浮层与本地偏好正式接入

## 为什么改

用户只能切换主题和查看资料，无法调整阅读大小与发送方式。按已审阅的[规划](../../../docs/01-规划与调研/设置浮层扩展-设计规划.md)，保留浮层，完成五类设置与可恢复的本地偏好。

## 范围与授权

2026-10-27 用户在收到规划和静态稿后要求“可以开始为我实现”，授权连续实现首版与本地验证。按新实现请求切换活动指针，上一工作空间任务保留待验收，未标记接受。无提交、push、发布、部署、接受/归档授权。

- 五类导航、旧入口映射、深浅/窄屏、焦点与行内重置。
- 主题卡、回答字号、系统优先减少动效、发送键、来源初始展开。
- 浏览器白名单保存、校验/异常降级与精确重置。
- 复用真实资料、共享退出、历史导航、帮助与真实前端版本。

`confirmed`：现有主题、同步默认/显式流式、引用终态、上下文与退出。`planned`：首版新设置。`partial`：工作空间实现待接受。`unknown`：实体设备/读屏效果。`out_of_scope`：后端、账户编辑/密码/密钥、组织切换、模型/检索参数、回答方式持久化、宽屏/强调色与云同步。

## 验证与风险

按 [design](design.md)、[tasks](tasks.md)、[规格](specs/rag-system/spec.md) 执行偏好/输入法/动效/来源聚焦回归、全量前端、含 vue-tsc build、DocAndScope/SensitiveLogs、封闭浏览器深浅宽窄和终态检查。应用内桥不可用时记录后采用既有独立本地浏览器验证方式。

真实 ask/embedding/rerank/judge/provider 与数据出站为 0，不新增依赖、不访问真实数据库/敏感配置。重点防止锁未释放、IME 误发、写失败误报成功和动效监听冲突。
