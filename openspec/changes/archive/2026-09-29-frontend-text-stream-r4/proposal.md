# R4 正式聊天页纯文本流

## 目标

在正式 `/chat` 页面提供可选择的纯文本流问答，并准确展示传输结果。现有同步问答继续作为默认模式。

## 背景

后端 `POST /api/qa/ask/stream` 只输出文本 `data:`、`[ERROR]` 与 `[DONE]`；当前正式聊天页只调用同步接口，旧 SSE composable 对错误和客户端中断判定不可靠。

## 范围

- 修复单一 SSE composable 的分帧、尾部、错误与中断处理。
- 在正式聊天页显式选择“纯文本流”，显示文本、传输标签和可确认的中断结果。
- 使用合成流测试与一次获授权的 KB17 真实 UI 流问答验证。

## 边界

不改后端 wire contract、provider 默认值、检索或生成策略；不提供流式引用、结构化最终业务状态或服务端可靠取消承诺。R2b 上传删除沿现有接口单独联调，不纳入此契约变更。
