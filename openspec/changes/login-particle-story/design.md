# 登录页粒子图样设计

## 💡 30秒人话设计主旨

现在的登录装饰会自己播放，但用户拨不动，也看不出它和知识库问答的关系。这次把右侧改成一组可以拨动的粒子：它们组成文档、检索关联和带引用的回答，滚轮能让变形停在任意中间位置，鼠标划过会轻轻拨开粒子，松开后再归位。左侧登录保持原有操作，页面不用为了展示动画而拉长。

## 改造前现状与契约变化

入口为 `rag-frontend/src/layouts/AuthLayout.vue`，通过 `LoginLogoMotion.vue` 挂载 `loginLogoMotion.ts`。现有 WebGL1 片元着色器绘制双翼，并按有效播放时间循环三种纹理；它没有独立点云、滚轮进度或鼠标扰动。旧组件、模块、SVG 和独立原型原样保留，新增实现后替换挂载点，便于定向切回。

本次以 MODIFIED delta 修改 `Login Brand Motion Presentation`，用三图样粒子故事替代冻结双翼/纹理轮换，并允许图样与暂停控制区；更新 `Login Motion Lifecycle And Safe Fallback` 以覆盖新控制器，新增局部滚轮与鼠标交互要求。认证、主题持久化和其他页面契约不变。

## 图样与视觉

| 图样 | 原创几何构成 | 正常 DOM 标题 |
| --- | --- | --- |
| 知识文档 | 有厚度的叠放书页、折角和短行纹理，避免只有矩形。 | 01 知识文档 |
| 检索关联 | 中心节点、分层邻近节点及连线，靠大小与位置体现关联。 | 02 检索关联 |
| 引用回答 | 回答卡片、文字行轮廓和三个来源小标记，不用细小点阵汉字承担阅读。 | 03 引用回答 |

沿用深浅主题、留白和配色变量，只用细点粒子与克制的强调色。画布为装饰并设置 `aria-hidden=true`；图样名称和原生按钮位于画布之外，不放入被隐藏的容器。首屏不加入整页标题轮播或长滚动区。

## 模块与数据流

- 新增 `rag-frontend/src/components/common/LoginParticleScene.vue`，负责画布、图样/暂停按钮、主题刷新和 Vue 生命周期；`AuthLayout.vue` 只替换挂载点并做必要右侧尺寸适配。
- 新增 `rag-frontend/src/utils/loginParticleGeometry.ts`，提供确定性采样、插值和滚轮归一化等纯计算；新增 `loginParticleMotion.ts` 负责原生 WebGL1、单一 RAF、输入及资源管理。
- 新增聚焦测试验证新实现。旧冻结原型测试继续只证明旧模块，不充作新效果验收。

数据流为：本地几何 → 三份等长坐标数组 → 目标进度 → 平滑进度 → 图样插值/散开 → 鼠标偏移/回弹 → 三维投影与点绘制。组件只传递选择/暂停/主题事件，不读取凭据、认证 store、问答内容或知识库。

三份模型采用相同数量、稳定顺序的采样，相邻图样按进度插值。固定种子产生散开方向，散开量两端为零、中段最大；反向操作从当前进度与速度继续，不重置端点。轻微呼吸不改变主要轮廓。

## 交互规则

- 首次显示知识文档，仅播放环境动画，不自动轮播图样。
- 连续进度固定为 `[0, 2]`。滚轮仅在画布内、渲染可用、未暂停/未减少动态效果时生效；按 `deltaMode` 归一化并限制单事件步长，避免一次跨过整套图样。
- 仅确实改变目标进度的可取消垂直事件才阻止默认行为。Ctrl/Meta 缩放、横向主导、端点继续向外滚动、画布外事件都放行；不可取消事件不驱动图样，避免页面和图样同时改变。不在 window/document/表单上拦截滚轮。
- 三个原生图样按钮可按 Tab 顺序到达，Enter/Space 选择，`aria-pressed` 标记选择。进度中间显示最近图样名称，不逐帧朗读；选择按钮不提交表单。
- 暂停时停止呼吸、平滑变形和鼠标扰动，显示最近完整图样。暂停中选图只绘制完整静态帧；继续从当前图样恢复，不补播后台时长。
- 鼠标只作用于画布，按运动轨迹对有限区域施加有界偏移，通过有阻尼回弹归位。离开、窗口失焦、隐藏、离屏、暂停和销毁均清除输入激活状态。
- 触屏不实现拖动刷子、不拦截 touchmove；通过按钮选图，保留纵向滚动和双指缩放。收窄后沿用上下排列，保证表单可达。

## 资源、失败与预算

沿用共享 theme store，每实例至多一条 RAF 调度链，连续绘制目标上限为 30 fps。初始粒子预算为桌面最多 4800、窄屏最多 2000（组件 CSS 宽度小于 360px），DPR 上限 1.5，画布最长边不超过 1200 设备像素。预算是上限，不是实际帧率达标声明；可在上述预算内调整并记录原因。

减少动态效果时显示完整静态图且停止连续调度，按钮仍可单次选图；隐藏/离屏停止绘制及有效时间累积。主题或尺寸变化在允许可见绘制时刷新，返回可见后应用最新状态。WebGL/浏览器能力不支持、资源创建/编译/链接/绘制失败或上下文丢失时显示既有同源 SVG，禁用不能生效的图样/暂停操作，成功恢复后再开放；不得中断登录。

卸载与部分初始化失败均清理 GPU、RAF、observer、媒体查询、document/window/canvas 监听。销毁幂等，迟到回调不重启、不写回卸载组件。

## 顺序与验收证据

先完成几何及控制纯计算，再接入控制器和正式组件，最后执行前端回归、正式 build 和浏览器验证。几何/控制测试覆盖数量、有限数、边界、端点、中间散开、反向连续、鼠标恢复及事件放行；生命周期测试覆盖失败、reduce、隐藏/离屏、主题、暂停、恢复和销毁。

视觉矩阵为 1440×900、1024×768、390×844，各含深浅主题；六张基准截图外，桌面两主题各记录三种完整图样和至少一张中间形态，可复用重合截图。交互通过实际操作记录确认，包括滚轮反向、端点/缩放放行、鼠标回弹、暂停/reduce、故障及路由重入；截图本身不证明这些行为。

现有 localhost 封闭合成预览用于键盘表单、登录成功/错误/等待及退出返回检查。后续证据集中放本 change 的 acceptance.md、visual-evidence.json 和本地截图目录；tasks.md 是唯一进度事实源。浏览器结果不外推真实认证、实体手机、硬件 GPU 或长期性能。最终运行 DocAndScope 并单独核对 diff 范围。

为检查控制器故障路径，可在现有封闭预览中增加独立测试页：使用实际生产控制器与浏览器 WebGL，模拟 reduce/document.hidden、分发受控滚轮事件并触发 WEBGL_lose_context。测试入口不进入正式路由/构建，模拟偏好与物理设备证据分开记录，不增加生产调试开关。

## 回退

旧实现原样保留。新效果不获接受时，只将 AuthLayout 的挂载切回旧组件，并定向处理本 change 新增使用点/文件；保留验证记录和未接受 delta。不得整体 reset/restore、回改接受归档或擅自合并 baseline。批准后的范围变化先更新设计并确认。

## 决策记录

### D1：在原生 WebGL 路线上写原创点云

- **当时面临哪几个选择**：可以引入 Three.js，可以移植参考项目的 Canvas 2D 运行时，也可以沿用当前原生 WebGL1 技术路线重新实现点云。
- **最终选了谁与理由**：选择原创 WebGL1。项目已有相关生命周期与降级经验，本次有限图样和扰动不需要新增通用库；参考仅用于理解机制，不复制实现或资产。
- **其他方案的代价**：Three.js 提供更多能力，但增加依赖和体积；直接移植需要处理来源、许可与另一套 CPU 绘制生命周期。本次不需要这些额外工作。

### D2：画布局部滚轮加按钮，登录保持普通页面行为

- **当时面临哪几个选择**：可以用长页面加 sticky，可以全页拦截滚轮，也可以限定到右侧画布并提供按钮替代。
- **最终选了谁与理由**：选择局部滚轮加按钮。用户不必滚过动画才能找到表单，键盘和触屏也能完整选图。
- **其他方案的代价**：长滚动适合介绍页，但增加当前登录页的浏览距离；全页拦截会改变常规阅读。局部方案则需要清楚提示及严格的事件放行测试。

### D3：统一点阵表达三种图样，旧实现保留以便回退

- **当时面临哪几个选择**：可以只加双翼纹理，可以同时叠加三图样与三纹理，也可以用统一点阵表达三种 RAG 图样。
- **最终选了谁与理由**：选择统一点阵，聚焦文档、检索和引用的变化；词标与旧静态 SVG 保留品牌连续性。
- **其他方案的代价**：只加纹理不能满足图样变形目标；两套变化叠加增加辨识和验收组合。三图样改变既有展示约定，因此必须用 MODIFIED delta 明确确认。

### D4：暂停/reduce 允许静态选图，渲染故障明确禁用操作

沿用现有主题与降级约定，新增可访问的暂停和选图控制。减少动态效果不剥夺用户选图能力；真正渲染失败时显示 SVG 并禁用无效操作，避免按钮看似成功但画面不变。真实认证/provider、其他页面、第三方代码和依赖均保持 out_of_scope。
