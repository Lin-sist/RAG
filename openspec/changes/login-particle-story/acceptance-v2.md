# 登录页粒子故事 · 第二轮客户端验收

Report status：`CLIENT_VALIDATED_AWAITING_ACCEPTANCE`。日期：2026-10-26。用户已回复“开始实现”，本轮实现与验证完成，等待视觉接受；baseline 接受/归档及 Agent 提交未授权。

## 为什么改、改完有什么变化

首轮三图样的随机散开容易形成方块，介绍文字也一直不变。第二轮在最前面加入现有双翼品牌标志，把独立横纵随机偏移改成围绕图样的有界圆盘分布，并让左侧标题和说明跟随实际粒子进度。登录表单始终保留，不随章节移动或重建。

正式顺序为品牌标志、知识文档、检索关联、引用回答，进度为 [0, 3]。共用章节定义消除按钮、几何、文字和测试页之间的计数差异。现有品牌路径只用于采样，原始 SVG 以及旧双翼组件/模块/原型均未修改。

散开最大平面半径为 0.26 装饰单位，半径平方分布使中心更密、外围更稀；稳定径向/切向坐标取代方形随机范围。前 72% 进度平滑转向目标轮廓，后段继续收紧散开；文字使用相同插值曲线。该参数由实际中间态审阅调整，减少等亮叠字与中段过度收缩，双向使用同一可逆路径。

投影使用固定缩放及宽高比适配，测试计入最大鼠标偏移、旋转、呼吸、纵深和点半径，检查各阶段仍留有边缘空间。没有用圆形遮罩掩盖裁边，也没有增加粒子预算或依赖。

## 浏览器与视觉证据

内置浏览器连接返回桥接不可用后，使用工作环境已有 Playwright 与本机 Chrome 的独立无头会话。没有安装包或下载浏览器。新增 [浏览器验收脚本](../../../rag-frontend/tests/login-particle-browser.mjs) 可重复执行；它只允许访问 127.0.0.1:5188，其他网络请求会被阻止并判失败。

运行方式是在 rag-frontend 目录执行 `node tests/login-particle-browser.mjs <现有 playwright/index.mjs 绝对路径> <证据输出目录>`，前提是现有合成预览已由 `node tests/preview.mjs` 启动。该验证入口不进入生产路由、依赖清单或构建。

证据见 [第二轮清单](visual-evidence-v2.json)，包含 8 个实现/测试源码哈希、10 个保留文件哈希、48 张原始截图及 4 张审阅拼图；详细 DOM/布局/交互数据保存在清单指向的 browser-records.json。首轮 [验收](acceptance.md) 与 [清单](visual-evidence.json) 保留原样证据含义，不替代第二轮结果。

- 深浅主题分别检查 1440×900、1024×768、390×844；四个完整场景均可达，页面无横向溢出，按钮高度均为 44 CSS px 或以上。窄屏四按钮分两行，暂停按钮独立可达。
- 桌面两主题的三段过渡均检查 25%/50%/75%，并保留全部中间态截图；已查看原始代表截图及覆盖全部 48 张的审阅拼图，没有发现紧贴画布边缘的平齐裁切。完整文档/回答本身保留矩形轮廓，中间态不再形成铺满画布的方形点云；最终审美接受仍由用户判断。
- 4800 个 Logo 采样点与浏览器 Path2D 读取的现有 SVG 三路径对照，两主题均为 0 个点在轮廓/描边之外，其中 539 个强调色点位于翼尖构成部分。它证明采样沿用品牌几何，不证明主观辨识度。
- 先填写合成用户名和密码，再切换四幕及中间态，输入节点身份、内容和表单起点保持不变；滚轮反向时输入框继续持有焦点。原生鼠标滚轮实际从 1.5 回退至约 1.4；固定分数截图由受控 DOM WheelEvent 精确设定，二者分别记录。
- 实际鼠标划过产生可观测偏移，离开后回弹归零。暂停与浏览器模拟 reduce 后连续帧停止，按钮可选择静态章节且文字对应；窄屏通过 Space 选图。
- 使用浏览器实际 WEBGL_lose_context 扩展触发丢失，品牌 SVG 与品牌文案同步显示且选图禁用；恢复后回到控制器实际图样及对应文案。不是通过 mock 代替 WebGL 丢失通知。
- 原有封闭合成登录用 Enter 提交；错误态得到本地合成错误，等待态显示“登录中...”后进入 /chat，登录画布数量归零。无 pageerror，外部网络请求为 0，真实认证/backend/provider 调用为 0。
