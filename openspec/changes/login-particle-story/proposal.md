# 登录页粒子故事：品牌开场、轮廓聚合与文案联动

## 为什么改

首轮三图样已经完成客户端实现与验证，用户认可整体效果，并提出三个具体改进：增加品牌 Logo 开场、减弱滚动中间态的方形边界、让左侧文字随图样变化。当前散开算法对各坐标轴叠加固定范围的均匀随机偏移，容易形成方块状点云；左侧标题也没有参与故事。本轮将这三个改进作为同一 change 的第二轮设计，不另开活动任务。

## 目标与范围

- 顺序扩展为“品牌标志 → 知识文档 → 检索关联 → 引用回答”，首次进入显示品牌 Logo，不自动切换章节。Logo 沿用现有双翼轮廓与强调色，不重新设计品牌标识。
- 用围绕图样的有界径向/切向散开替换各轴独立均匀偏移。变形中段保持松散轮廓，接近目标章节时收紧细节；投影预留安全空间，避免点云齐刷刷贴着画布边缘。
- 左侧两行标题与一句说明使用同一连续进度进行淡入和轻微位移。表单固定、输入保留，暂停/reduce/故障时文字与画面一致。
- 保留局部滚轮、鼠标刷动回弹、四个原生选图按钮和暂停控制；窄屏控制区允许换行，不挤压点击区域。
- 沿用原创原生 WebGL1，不新增依赖。旧双翼组件、模块、静态 SVG 和独立原型继续保留；认证、主题持久化及其他业务页不改。

具体文案、变形路径和验证条件见 [design](design.md)，行为契约见 [spec delta](specs/rag-system/spec.md)。
