# 登录页粒子图样与交互改造

## 为什么改

改造前登录页右侧用双翼图形循环切换点阵、交叉和字符纹理，能够表达品牌，但用户无法用滚轮控制图样，也无法拨动粒子。本次借鉴 HireFerry 的连续变形和鼠标刷动原理，制作与 RAG 用途相关的原创图样，直观表达“资料进入、检索关联、回答有出处”。

## 目标与范围

- 仅改造正式 `/login` 右侧装饰及其控制区，保留现有左右布局、词标、标题、共享主题和真实登录表单。
- 三种图样为“知识文档”“检索关联”“引用回答”，同一组粒子连续散开、变形和聚合，取代正式页的细点/交叉/字符轮换。
- 首次进入显示知识文档并轻微呼吸，不自动轮播。鼠标悬停画布时，滚轮可连续前后变形；三个图样按钮供键盘与触屏选择。鼠标划过可拨开邻近粒子，离开后逐渐回位。
- 增加暂停/继续按钮。暂停或减少动态效果时停止连续动画，图样按钮仍可选择完整静态图。
- 沿用原生 WebGL1，以项目内原创几何和交互实现，不新增依赖、不移植参考项目代码。旧组件、模块、静态 SVG 与独立原型原样保留以便回退。

## 授权与阶段

用户于 2026-10-26 要求“制定一份登录页图样改造计划，然后开始执行”，并指定使用 OpenSpec 和新的 Vibecoding 工作流。四类方案文件完成后，用户通过设计确认明确回复“确认方案，开始实现与验证”。本 change 据此进入实施，按相同范围连续实现与验证，不逐切片重复审批。

本 change 尚无 Agent 暂存/提交、baseline 接受/归档、push、PR、发布或部署授权；其他任务授权不迁移至本 change。真实认证/backend/provider/ask/embedding/rerank/judge 调用预算均为 0；预览仅用 localhost 合成数据，无用户数据出站和业务持久化。

## 交付与验收

实施分为图样与变形、正式组件与交互、回归与视觉证据三个切片；见 [tasks](tasks.md)。要求几何/控制器聚焦测试、现有前端回归、含 vue-tsc 的正式 build、DocAndScope、深浅三视口及鼠标/滚轮/键盘/降级的浏览器检查。未完成的检查保留，不以单测替代视觉或真实设备证据。

主要风险是图样辨识不足、滚轮影响页面阅读及资源泄漏，分别通过原创几何轮廓、局部事件边界和生命周期测试约束。具体方案见 [design](design.md)，契约变化见 [spec delta](specs/rag-system/spec.md)。
