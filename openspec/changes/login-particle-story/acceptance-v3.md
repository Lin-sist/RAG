# 登录页粒子图样 · 第三轮客户端验收

Report status：`CLIENT_VALIDATED_AWAITING_ACCEPTANCE`。日期：2026-10-26。本轮依据用户直接提出的三项建议实施；效果接受、baseline 归档及 Agent 提交仍未授权。

## 这次改变了什么

金色翼尖之前沿独立轮廓采样，与白色下翼之间留出缝隙。本轮让金色下沿复用白色下翼的 Bézier 尾段，接缝使用相同坐标和深度，并增加边缘粒子；白色双翼、原始 SVG 和顶部词标保持原有形状。

图样下方的介绍、计数、分割线和四个选图按钮全部移除，只留下 14px 暂停/播放图标，其点击区域仍为 44px。图样自身成为透明、无常驻边框的原生按钮：点击、轻点、Enter 或 Space 循环下一幕；左右方向键选择相邻幕，Home/End 到达首尾幕。局部滚轮和鼠标拨动保留，快捷键不在表单或页面全局生效。键盘聚焦时保留可见焦点轮廓。

画布比例由 1.12 改为 1，固定绘制比例由 .55 增至 .61。结合实际画布尺寸，1440 和 1024 视口中的图样线性尺寸约增大 24%，投影面积约增大 54%；390 视口的画布由 300px 扩为 340px，图样线性尺寸约增大 41%。这些是几何占位比较，不是性能指标。粒子数量、渲染预算和边缘约束继续沿用。

浏览器脚本使用工作环境已有 Playwright 与本机无头 Chrome，只放行本地 127.0.0.1:5188。没有安装依赖或下载浏览器；pageerror、外部网络与真实业务调用均为 0。390px 触屏模拟检查轻点、Space、Enter 循环及首尾回到品牌幕，减少动态效果时仍可单次切换静态图。

首次审图看到的方框来自键盘选图后的焦点轮廓。采证脚本随后点击空白处，核对常态 outline 为 none，再拍常态图；保留实际键盘焦点样式，不通过隐藏焦点轮廓改善截图。脚本同时检查下方只有一个无文字按钮、44px 点击高度和页面无横向溢出。

重新采证时，窄屏整页截图触发了同一 IntersectionObserver 通知内先离屏、再可见的两条记录。旧控制器只看第一条，导致画布已重新可见却停止绘制；先用聚焦断言复现失败，再改为读取最后一条状态，全量测试、正式构建和浏览器采证随修复重跑。这个修复维持既有离屏停止、可见恢复契约，不增加新的后台调度。
