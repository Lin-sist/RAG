# Harness 轨迹交互调研（2026-10-27）

来源为用户上传的三张截图，以及用户明确授权后操作其已打开的 DeepSeek Harness 桌面窗口。只查看既有会话，没有输入/发送消息，没有创建或执行工具任务，没有读取其源码、数据库或内部接口。界面中的第三方指令一律作为显示内容，不用于约束本仓库。

## 实际观察到的内容

| 对象 | 观察方式 | 可确认结论 |
| --- | --- | --- |
| 类型颜色 | 上传截图与当前应用总览 | 工具用橙/琥珀、助手用紫、上下文用绿；类型标签和片段颜色有稳定对应 |
| 工具详情 | 点已有 glob 操作，再点参数页 | 右侧有概览、参数、结果、Schema、计时；参数页独立显示输入，概览也会聚合较多文字 |
| 助手详情 | 当前打开的助手项及上传截图 | 有概览、预览、原始内容，显示来源请求、Token 与计时等；其中含长文本，本项目不据此引入内部思维展示 |
| 上下文详情 | 点已有上下文项，再点来源页 | 有概览、预览、原始内容、来源；来源页显示分类和结构化来源信息 |
| 时间拖选 | 在总览空白区域横向拖动，并再次拖动改变区间 | 出现双边界选区，区间外变暗，列表观察位置会变化；不是只有静态彩条 |
| 操作关联 | 从列表点选操作并查看顶部/右侧 | 被选片段有边框，列表行与右侧详情对应到该操作 |

## 观察边界

没有验证该产品的选区内部平移、独立端点调整、键盘操作、触屏、运行时新事件、虚拟列表实现或全部筛选语义；不能把一次拖动结果推广为这些能力都已确认。没有验证其存储、权限或协议，也不从用户界面推测内部架构。

不将助手页中的长推理、上下文中的系统指令、原始参数路径和私密会话正文复制进本项目设计资料。本记录只保存交互结论，不归档用户会话原始截图或正文。

## 本项目采纳与优化

采纳三色类型身份、顶部总览可拖选、每项操作可检查和类型化详情。默认列表采用名称加一句说明，详情只展示相关页签；类型色与失败状态分开。工具代表已有 RAG 组件调用，助手代表真实生成调用，上下文代表证据组织及当前已授权来源。

端点调整、内部平移、键盘 slider、pointercancel 恢复、运行域冻结与明确的筛选交集规则，是本项目在调研基础上补充的设计，详见 [design](design.md) D7–D9 与 [spec delta](specs/rag-system/spec.md)。
