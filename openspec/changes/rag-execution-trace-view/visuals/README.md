# 轨迹视觉与交互稿

## 第二版：三色类型与滑动选区（2026-10-27）

当前审阅入口为 [trace-v2.html](trace-v2.html)：这是可离线打开、无依赖、无网络请求的单文件交互设计稿，不是正式 ChatPanel。也可在本次会话的 [localhost 预览](http://127.0.0.1:5194/trace-v2.html)体验；该地址依赖本机预览进程，停止后可直接打开 HTML。

- 工具为琥珀色，助手为紫色，上下文为青绿色；颜色表示类型，状态由独立标记表达。
- 顶部支持正反拖选、端点调整、选区平移及键盘边界调整；“全部时间”恢复范围，类型/阶段筛选保留。
- 每个操作提供名称与一句说明。工具看参数/结果，助手看回答/计时，上下文看本次已授权来源。
- 数据全部为固定模拟样例；输入框可验证草稿保留，但发送按钮禁用，不连接任何业务 API，不保存历史。

## 第一版保留资料（2026-10-26）

三张稿只用于审阅布局、信息密度和主题方向，全部耗时、状态、片段数和降级均为模拟数据，不代表项目实测，不是已实现界面或浏览器交互验收。侧栏/输入框仅作上下文占位，正式实施沿用现有组件。

| 稿件 | 检查重点 |
| --- | --- |
| [浅色默认总览](01-overview-light.png) / [SVG](01-overview-light.svg) | 1440×900；四组阶段只显示必要信息，详情关闭 |
| [深色选中详情](02-detail-dark.png) / [SVG](02-detail-dark.svg) | 1600×960；选中检索后展开安全事实，降级仅局部强调 |
| [窄屏总览](03-mobile-light.png) / [SVG](03-mobile-light.svg) | 390×844；保留名称、状态、相对时间和耗时，详情交互待实施 |

这三张稿不是完整深浅六视口验收矩阵；中屏行内展开、窄屏 sheet、运行中更新和键盘语义以 [design](../design.md) 为准，须在实现后单独验证。问答选择器仅示意多条已加载记录时的布局，单条实际记录应隐藏该选择器。

[生成脚本](render_wireframes.py)只使用已有本机 Python/PyMuPDF 生成 SVG 和 PNG，无网络访问、不安装依赖、不执行问答或应用代码。SVG 为可编辑源稿，PNG 为本地渲染预览。
